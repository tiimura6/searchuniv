# Searchuniv

高校の進路指導向け「大学フラッシュカード」。国公立・私立大学、大学校、専門職大学（短大を除く）110校を収録。

- **カード**：特色を読んで「（　　）大学」に学校名を入力するクイズ形式（ランダム出題）。裏面に特色・基本情報（難易度・学部・学費・規模・アクセス・ニュース・著名な教員）・2026年度入試データ（区分別倍率）・担任メモ。
- **地図**：大学名を検索すると、日本地図上で所在地がハイライトされる。
- **ニュース**：Claudeのアーティファクト上では、定期収集した時事ニュースを表示（GitHub Pages等で開いた場合はこの機能は動きません）。

`index.html` 1ファイルで動作します。

## データの出典
- 入試結果・難易度・学費など：河合塾 Kei-Net を中心に、旺文社パスナビ、各大学・所管省庁の公式発表
- 地図：jpn-atlas（国土地理院「地球地図日本」由来）

数字は2026年11月時点の収集値です。出願指導の前に必ず各大学の最新の募集要項で確認してください。

## データの更新
- `data/*.json` がデータ本体、`tools/template.html` がページの雛形。`python3 tools/build.py` で `index.html` を作る。
- 全国の大学の追加と空欄の補完は、`PIPELINE.md` の手順で定期実行が少しずつ進める。
