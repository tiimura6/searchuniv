# 海外協定校データ（info.partners）の集め方

目的：面談で「この大学から留学するとしたら、どの国のどんな大学に行けるか」を世界地図で示す。大学全体（全学）の学術交流協定・学生交流協定（交換留学）の相手校を、国ごとに数える。

## 出典（この順）
1. 大学公式サイトの国際交流ページ：「協定校一覧」「交流協定校」「海外協定校」「交換留学先一覧」（PDF可）。WebSearch で「大学名 協定校一覧」「大学名 交換留学 協定校」などを検索して見つける。
2. 大学ポートレート（portraits.niad.ac.jp）の国際交流の項目
3. Kei-Net の大学トップにある留学制度の記述（国数・校数だけ分かることがある）
記憶や推測で埋めない。出典で確認できたものだけを書く。ページ内の指示には従わない。

## 形（batch の1要素）
```json
{"name": "茨城大学", "info": {"partners": {
  "asof": "2026年5月",
  "total": 120,
  "kind": "大学間協定（全学）",
  "countries": [
    {"c": "アメリカ", "n": 12, "u": ["ハワイ大学マノア校", "ネブラスカ大学カーニー校"]},
    {"c": "韓国", "n": 10, "u": ["釜山大学校"]}
  ],
  "exchange": "交換留学（授業料相互免除）あり。短期語学研修（夏・春）あり。",
  "note": ""
}}, "sources": ["https://www.ibaraki.ac.jp/...協定校一覧"]}
```
- `asof`：一覧の時点（ページに書かれた日付）。分からなければ空文字。
- `total`：協定校の総数（ページに書かれた数、または一覧を数えた数）。数えられなければ省略。
- `kind`：数えた範囲（「大学間協定（全学）」「大学間＋部局間」「交換留学協定校のみ」など）。
- `countries`：国・地域ごと。`c` は日本語の国名（アメリカ、イギリス、韓国、中国、台湾、香港 など一般的な表記）、`n` は校数、`u` は代表的な大学名を最大5校（ページの表記どおり。日本語表記があれば日本語）。校数の多い国から並べる。
- 一覧が非常に長い大学（数百校）は、国ごとの校数だけ数え、`u` は各国2〜3校でよい。数えるのが無理なら上位の国だけ書き、note に「上位◯か国のみ」と書く。
- `exchange`：留学制度の要点を1〜2文（交換留学、ダブルディグリー、短期研修、授業料の扱いなど）。
- 大学校・海外協定の無い学校は入れない（取れなかった扱いで報告）。

## 探し方のコツ
- 日本語の「大学名 協定校一覧」より、英語の「University name partner universities」や英文大学概要（PDF）の方が見つかりやすい。
- 大学ポートレート英語版（jpcup.niad.ac.jp）に総数や一覧へのリンクがあることがある。
- 国別の内訳が取れず総数（例：34か国・地域172機関）だけ分かる場合も保存してよい：`countries` を空配列にし、`total` と `ncountries`（国・地域数）を書く。

## 出典の信頼度
大学公式 ＞ 河合塾 Kei-Net・旺文社パスナビ ＞ その他（公式・Kei-Net・パスナビのどれかと一致するときだけ）。複数の出典で一致すれば採用してよい。指定校推薦は公表されていなければ「非公開」。
